🧮 Calculs Posés & Décompositions - Classe Adaptative
Un outil de numération et de calcul intelligent pour le cycle 2 et le cycle 3.

Cette application web interactive est conçue pour l'affichage sur TBI (Tableau Blanc Interactif) et pour une utilisation individuelle ou en groupe. Elle permet de travailler les opérations posées, les arbres de calcul et le calcul "à trous", tout en offrant une remédiation immédiate grâce à l'intelligence artificielle Google Gemini.

🚀 Fonctionnalités Clés
1. Trois Modes de Travail

Entraînement : Pour une pratique libre ou guidée.

Sprint : Pour automatiser les procédures avec un défi de rapidité.

Duel / Équipe : Pour favoriser l'émulation et la coopération entre élèves.

2. Formats d'Exercices Modulaires

Calcul Posé : Addition, soustraction, multiplication et division (avec potence).

Arbre de Calcul : Décomposition canonique (Milliers, Centaines, Dizaines, Unités) avec étages de calculs intermédiaires pour les produits partiels.

Calcul à Trous : Pour renforcer la compréhension de la technique opératoire.

3. Différenciation en Temps Réel

Chaque carte de calcul est indépendante. Vous pouvez configurer pour chaque élève :

Le type d'opération.

Le champ numérique (jusqu'à 1 000 000).

Le type de nombres (Entiers ou Décimaux).

4. Tuteur IA (Google Gemini)

Au verso de chaque carte, après la validation, une intelligence artificielle analyse l'erreur spécifique de l'élève (erreur de retenue, décalage de colonne, oubli du zéro, etc.) et lui donne un conseil personnalisé sans donner directement la réponse.

🛠 Installation sur GitHub Pages
L'application est "monobloc" (HTML/CSS/JS). Pour l'héberger :

Créez un nouveau dépôt (repository) sur votre compte GitHub.

Importez le fichier sous le nom de index.html.

Allez dans Settings > Pages.

Sous Build and deployment, choisissez la branche main et cliquez sur Save.

Votre application est en ligne à l'adresse : https://votre-pseudo.github.io/votre-nom-de-depot/.

💡 Intégration dans Google Sites
Pour intégrer cet outil dans votre Google Site de classe :

Dans Google Sites, choisissez Insérer > Intégrer.

Collez l'URL de votre page GitHub Pages.

L'application s'affichera directement dans votre page de classe et restera interactive pour vos élèves.

🛡️ Sécurité & Confidentialité
Clé API : L'application nécessite une clé API Google AI Studio pour le tuteur. Pour une utilisation en classe, assurez-vous de configurer des restrictions de quota.

Données : Aucune donnée élève n'est collectée ou stockée sur un serveur tiers.
